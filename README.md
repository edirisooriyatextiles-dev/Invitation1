# Edirisooriya Textiles — Grand Opening Invitation (Invitation2)

Interactive digital grand opening invitation and heritage showcase for **Edirisooriya Textiles** (*Fibres • Fabrics • Fashion*).

Built with [Next.js](https://nextjs.org), featuring:
- Cinematic curtain opening intro with logo and gold line animation
- Responsive typography with Fraunces & Hanken Grotesk Google Fonts
- Live countdown ticker with rolling digit roll animation
- Parallax depth and scroll progress indicator
- Google Calendar invite generation and instant WhatsApp RSVP sharing
- Vercel ready configuration

## Getting Started

First, install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the application.

## Production Build & Deploy

To build for production:

```bash
npm run build
```

To deploy to Vercel:

```bash
npx vercel
```
